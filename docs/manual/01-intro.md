# 01 概要と前提

単一WorkerにHTTP APIとDurable Objectスケジューラ、D1、React/Kumo管理画面をまとめた製品です。モノレポやインストーラーではありません。

| 項目 | セルフホスト | The Harness Cloud |
|---|---|---|
| Worker / D1 / 秘密の管理 | 自分で配置・更新・バックアップ | ホスト側で管理 |
| 管理画面 | 自分のWorker URL | Cloud側のワークスペースから開く |
| Threads接続 | Metaで発行したユーザートークン | 実際の投稿には同様に有効な接続が必要 |
| この手順のmigration | 自分のD1に実施 | ホスト運営者の更新手順に従う |

APIキーを持つ人は環境全体の管理者です。顧客ごとにWorker・D1・秘密を分離します。接続確認や下書き保存だけでは投稿しません。

OAuthログイン、自動更新、成否不明の照合UIは未実装。Threads API自体にはWebhookがありますが、この製品はWebhook受信を使わず、投稿状態はAPIで取得します。MetaのWebhook設定は現行版の動作に不要です。実アカウントでテキスト単発・連投・PNG画像・MP4動画・画像と動画2件のカルーセル・予約テキストと6指標取得を確認済みです。ブラウザでの見た目・再生確認や全素材形式の実地検証は含みません。[検証範囲](../reviews/live-media-verification-20261026.md)。
