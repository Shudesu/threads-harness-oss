# 05 接続・確認・再接続

1. 自分のWorker URLを開き、`API_KEY` でログインします。キーはこのタブのsessionStorageに保持され、ログアウトで削除されます。
2. 「Threadsアカウントを接続・更新」を開き、[02章](02-meta-app.md)で発行したユーザートークンを入力します。
3. 「接続を確認して保存」を押します。プロフィールと3権限を確認してから暗号化保存します。失敗時は既存の接続を上書きしません。
4. 表示された `@username`、権限確認時刻、トークン期限、データアクセス期限を確認します。接続成功は投稿成功の保証ではありません。

「接続状態を確認」は保存済みトークンを再診断します。期限不明の旧データもここで確認します。失効エラー（Meta 190）を検出したアカウントは再接続が必要と表示されます。単なる管理画面の一覧更新はMetaへの再診断ではありません。

再接続は同じアカウントの新しいトークンを同じ欄に貼ります。アカウントID、下書き、投稿履歴を保持します。`needs_review` の投稿は再接続しても自動再送しません。

「切断」はこの環境の保存済みトークンを消し、以降の送信を止めます。履歴・所有関係は残ります。Meta側のアプリ許可自体を取り消す操作ではありません。すでに送信中だったリクエストは取り消せないため、Threads側で結果を確認してください。
