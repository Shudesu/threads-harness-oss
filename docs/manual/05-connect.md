# 05 接続・確認・再接続

1. Cloudのワークスペースから管理画面を開くと、SSOのログイン情報で自動的に入室します。直接Worker URLを開く場合は `API_KEY` でログインします。キーはこのタブのsessionStorageに保持され、ログアウトで削除されます。
2. サイドメニューの「アカウント設定」→「Threadsアカウントを接続・更新」を開き、[02章](02-meta-app.md)で発行したユーザートークンを入力します。
3. 「接続を確認して保存」を押します。プロフィール・3権限・実期限と投稿枠取得を確認してから暗号化保存します。投稿枠が0でも接続自体は保存できます。失敗時は既存の接続を上書きしません。
4. 表示された `@username`、権限確認時刻、トークン期限、データアクセス期限を確認します。接続成功は投稿成功の保証ではありません。

「接続状態を確認」は保存済みトークンを再診断します。期限不明の旧データもここで確認します。失効エラー（Meta 190）を検出したアカウントは再接続が必要と表示され、未処理の予約を保持したまま一時停止します。単なる管理画面の一覧更新はMetaへの再診断ではありません。

再接続は同じアカウントの新しいトークンを同じ欄に貼ります。アカウントID、下書き、投稿履歴を保持します。`needs_review` の投稿は再接続しても自動再送しません。

「切断」はこの環境の保存済みトークンを消し、以降の送信を止めます。履歴・所有関係は残ります。Meta側のアプリ許可自体を取り消す操作ではありません。すでに送信中だったリクエストは取り消せないため、Threads側で結果を確認してください。

再接続後に一時停止中と表示される場合は、残件を確認して「残っている予約を再開」（残件0なら「予約の一時停止を解除」）を押します。接続の復旧と予約の再開は別の操作です。

## 複数アカウント

アカウント設定の接続フォームへ、追加したい本人のThreadsトークンを入力します。異なるThreads IDは別アカウントとして追加され、同じIDなら再接続になります。一覧に各ID・期限・未処理件数が表示され、「このアカウントを操作」またはサイドバーで切り替えます。選択はこのタブのセッションに記憶されます。未保存の原稿があれば切替前に確認します。

下書き・集計・スケジューラ・失効による停止はアカウント別です。一方、APIキーは全アカウントを管理でき、スタッフ別の閲覧/投稿権限はありません。別のお客様は別ワークスペースへ分けてください。Cloudで作成できる環境数や利用枠は契約条件に従います。

MCP/APIの設定は管理画面の「MCP・API連携」を開きます。接続トークンをAIへ渡す必要はありません。
