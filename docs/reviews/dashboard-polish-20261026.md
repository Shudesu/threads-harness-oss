# ダッシュボードの情報整理 — 2026-10-26

v0.2.1では「操作対象 → 次にすること → 投稿状況 → 最近の動き」の順に整理。大きな正式提供バナーを下部のお知らせへ移し、日常の操作を優先する。

- 接続状態・既知の期限切れ、要確認の投稿、予約停止、未保存原稿、期限接近、下書き、公開待ちから次の操作を選ぶ。未知の状態を正常とは表示しない。
- 3つの件数に役割を付記。最近の原稿は短い行表示とし、投稿管理の該当箇所へ移動する。直接送信しない。
- 予約なし・再開待ち・処理中・日時到来後の待機を区別。処理開始と公開完了を混同しない。
- 表示/いいね/返信は保存済みの値と明記。取得件数/時刻を併記し、架空の推移・割合を追加しない。
- 概要APIにprocessing/nextScheduledAt/lastPublishedAtを追加。アカウント全件・非表示除外で計算し、最新200件の表示上限から独立させる。

既存の投稿/接続/予約/権限/公開確認手順は変更しない。DB migrationなし。143テスト、型/ビルド、Python3、workerd/DO検証で確認。ブラウザ/Playwright/Computer Useは使用せず、DOMテストまでの確認であり、実機の描画確認は未実施。
